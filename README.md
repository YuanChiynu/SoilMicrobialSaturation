# High resource-surplus levels compromise soil microbiome resistance to global changes

Analysis code and primary data for the manuscript submitted to *Ecology* (ECY26-0595).

Yuan Chi, Dong Liu, Zelin Wang, Kaifang Liu, Yuan Du, Yi Duan, Xin Hu, Guangbing Xu,
Xinrui Han, Jianxing Li, Rongxiao Che

---

## Overview

Soils frequently experience resource-surplus states, either after disturbances that kill microbial
biomass and release necromass or after pulse inputs of external resources. We generated a
resource-surplus gradient by mixing fresh and sterilized soil to obtain relative initial propagule
densities of 10%, 40%, 70% and 100%, for three ecosystems (cropland, forest, grassland), and then
exposed the microcosms to six global-change treatments: CK (control), C (organic carbon addition),
N (nitrogen addition), pH (acidification), W (warming) and D (drought).

The repository contains the rarefied amplicon tables, the metagenomic functional profiles, the qPCR
copy numbers and the soil physicochemical measurements used for the analyses, together with the R
scripts that reproduce every figure and supplementary table.

Throughout the code, `RS` denotes the effect of resource-surplus level (the propagule-density
gradient) and `T` denotes the effect of the global-change treatment.

## Repository structure

```
.
├── data/                  primary data (see below)
├── scripts/               R scripts, one per figure / supplementary table
├── output/                created at run time (not tracked)
├── LICENSE.txt
└── README.md
```

`output/` is generated by the scripts and is ignored by git. Each script writes its figures to
`output/<Figure>/` and its statistics tables to `output/<Figure>/stats/`.

```
data/
├── amplicon/
│   ├── prokaryote/        16S rRNA gene: OTU_rare_16S_all.csv, group.csv, metadata.txt
│   └── fungi/             ITS region: OTU_rare_ITS.csv, group.csv, metadata.txt
├── metagenome/            KO.csv, KO_annotated.csv, group.csv,
│                          reads_ra.csv.gz, gene_copies2.csv.gz,
│                          by_density/gene_copies_density_{10,100}.csv
├── qpcr/                  16S_copynum.csv, ITS_copynum.csv
├── soil_properties/       DOC.csv, NH4.csv, NO3.csv, AP.csv, ph.csv,
│                          nitrogen/redone/{NH4,NO3}.csv
└── validation/            dilution verification experiment
    ├── prokaryote/        Verify_rare_16S.csv, Verify_rare_16S_Cropland.csv, group.csv, 16S_alpha.csv
    └── fungi/             Verify_rare_ITS.csv, Verify_rare_ITS_Cropland.csv, group.csv, ITS_alpha.csv
```

Within `amplicon/*/`:

* `by_ecosystem/<marker>_{C,F,G}.csv` — OTU tables split by ecosystem, used for NMDS and
  community-composition panels.
* `by_ecosystem_density/<marker>_<ecosystem>_<density>re.csv` — OTU tables split by ecosystem and
  propagule density, used for the pairwise PERMANOVA heat maps (Figs. S10 and S11).
* `similarity_group{1,2}.csv` — sample grouping used for the CK-versus-treatment similarity panel
  of Fig. 2.

Notes

* `reads_ra.csv.gz` and `gene_copies2.csv.gz` are gzip-compressed because each uncompressed table
  is about 250 MB. The scripts read them directly with `gzfile()` or `data.table::fread()`, so no
  manual decompression is needed.
* Density levels in the grouping files are coded `10%re`, `40%re`, `70%re` and `100%re` (16S and
  ITS) or `10%`, `40%`, `70%`, `100%` (metagenome). The scripts map these codes to the displayed
  labels 10%, 40%, 70% and 100%.
* `KO.csv` and `KO_annotated.csv` keep the original KEGG orthology identifiers, gene names and
  functional descriptions; the `class` and `cycle` columns were translated to English
  (carbon / nitrogen / phosphorus / sulfur) so that they can be used as grouping variables.
* Amplicon tables are rarefied; metagenomic tables are relative abundances (`reads_ra.csv.gz`) and
  per-gene copy numbers (`gene_copies2.csv.gz`).

All statistics annotated on the figures (PERMANOVA terms, ANOVA and LSD letters) are computed
inside the scripts from the primary tables, so no intermediate result files are needed.

## Scripts

| Script | Figure / table | Content |
|---|---|---|
| `Fig1.R` | Fig. 1 | Alpha diversity (richness, Shannon) and within-ecosystem community dispersion |
| `Fig2.R` | Fig. 2 | NMDS of community structure, PERMANOVA, CK-versus-treatment similarity |
| `Fig3.R` | Fig. 3 | NMDS of functional gene composition and functional community similarity |
| `Fig4_network_properties.R` | Fig. 4A | Co-occurrence network construction and topological properties |
| `Fig4_networks.R` | Fig. 4A | Network layout and drawing |
| `Fig4_robustness.R` | Fig. 4B | Robustness to random and degree-first node removal |
| `FigS3.R` | Fig. S3 | Dilution verification experiment: PCoA and richness |
| `FigS4.R` | Fig. S4 | Soil physicochemical variables and their community dispersion |
| `FigS5.R` | Fig. S5 | qPCR copy numbers and their community dispersion |
| `FigS6.R` | Fig. S6 | Taxonomic composition of the communities |
| `FigS10.R` | Fig. S10 | Pairwise PERMANOVA heat maps across treatments, 16S rRNA gene |
| `FigS11.R` | Fig. S11 | Pairwise PERMANOVA heat maps across treatments, ITS region |
| `FigS12.R` | Fig. S12 | Gene-level community dispersion from 10% to 100% propagule density |
| `FigS13.R` | Fig. S13 | Effect-size heat map of functional gene abundance (Hedges' g) |
| `FigS15.R` | Fig. S15 | Threshold sensitivity of the co-occurrence networks |
| `FigS16.R` | Fig. S16 | Responses of life-history strategy groups along the density gradient |
| `TableS8_LEfSe.R` | Table S8 | Differential abundance with LEfSe |
| `utils_legend.R` | — | Helper that exports a standalone legend for a ggplot object |

Run order for composite figures:

* Fig. 4: `Fig4_network_properties.R` → `Fig4_networks.R` (and/or `Fig4_robustness.R`), because the
  first script writes the screened edge and node tables that the other two read.
* Fig. S16: run `TableS8_LEfSe.R` first; `FigS16.R` reads the LEfSe differential-taxa table and the
  sample-level relative abundances it writes under `output/TableS8_LEfSe/`.

`Fig2.R` and `Fig3.R` cache their NMDS results under `output/`. Set `RECOMPUTE=1` to force a
recalculation.

## Requirements

`ggplot2`, `dplyr`, `tidyr`, `cowplot`, `ggpubr`, `scales`, `vegan`, `permute`, `igraph`,
`agricolae`, `emmeans`, `openxlsx`, `data.table`, `microeco`, `magrittr`

## Running

Run every script from the repository root, for example

```bash
Rscript scripts/Fig1.R
```

Paths inside the scripts are relative to the root (`data/...`, `scripts/...`, `output/...`), so the
working directory must be the repository root. Each script creates its own output directory.
